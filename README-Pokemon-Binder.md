# Pokémon Binder

## iPhone MVP

A SwiftUI prototype for tracking a Pokémon card collection.

### Features
- National Pokédex overview
- Collected / missing state
- Search by Pokémon name or number
- Filters: all, collected, missing
- Collection progress
- Local persistence

### Roadmap
- TCG sets and card numbers
- Multiple cards per Pokémon
- Card images
- Card scanning
- iCloud sync
